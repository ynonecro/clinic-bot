# Clinic Bot

Telegram-бот для записи к врачу в медицинской клинике.

## Возможности
- Запись к врачу: выбор специалиста и свободного времени
- Просмотр своих записей
- Защита от двойного бронирования слота (уникальный индекс в БД)

## Стек
- Python 3.10+
- aiogram 3 (асинхронный Telegram Bot API)
- PostgreSQL + SQLAlchemy 2 (ORM)
- python-dotenv (конфигурация)

## Структура
- `bot.py` — хэндлеры и запуск бота
- `db.py` — модели SQLAlchemy и функции работы с БД
- `config.py` — чтение переменных окружения
- `seed.py` — наполнение БД тестовыми врачами
